# How are the observed value and the change from baseline arranged? (`tfl.vs.layout`)

The answer fixes the arrangement of the vital signs table by visit: observed values and
changes from baseline next to each other, or in separate blocks. The numbers are the same.

## Where it is stated

- SAP table shells: the layout of the vital signs table is the main source.
- SAP: vital signs section ("observed values and changes from baseline will be presented").
- Protocol: never. The text alone rarely settles it.

## Words to look for

- `side_by_side`: a shell with "Observed" and "Change from baseline" column groups next to
  each other and one row per visit; "presented alongside".
- `stacked`: a shell with a block of observed values followed by a block of changes from
  baseline; "presented separately", "in a separate section of the table".

## Traps

- "Observed values and changes from baseline will be summarized" names the content, not the
  arrangement. Without a shell or a clear word, the entry is silent.
- Two separate tables, one of observed values and one of changes, are not the same thing as
  `stacked`, which is one table with two blocks. Report the passage with the answer.
- Change from baseline is shown for post-baseline visits only in both alternatives; an empty
  change cell at Baseline is not a sign of either layout.
- Silent documents: use the house default and cite the house standard.
