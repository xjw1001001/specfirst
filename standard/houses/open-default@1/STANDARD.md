# House standard open-default@1

Document: house
Catalog: specfirst-m1 draft-1

This is the house standard open-default@1: an open default for analysis data and safety tables, built from public standards only.

Each numbered statement below is a default. It holds for a study whenever the study's protocol and statistical analysis plan do not state the decision. A decision taken from this document has the status `default` and the class `house_default`, and cites the statement by its anchor, for example `doc:house#1/s1`. A line that starts with "Meaning:" repeats what the catalog says the statement means; it is not a statement of its own.

The statements are in the standard form of the decision catalog: a parser reads each one back to its decision. Do not edit this file by hand. It is rendered from the catalog and from `house.yaml`; `specfirst gate std-1` fails when it differs.

## 1 Treatment and exposure (mod-treatment)

[1/s1] Planned treatment is the planned arm of the subject (DM.ARM).

[1/s2] Actual treatment is the actual arm of the subject (DM.ACTARM).

[1/s3] The treatment start date is the earliest start date of an exposure record with a dose.

Meaning: An exposure record has a dose when EXDOSE is above zero, or when EXDOSE is zero and EXTRT contains PLACEBO. Which partial dates take part is decision trt.date.imputation.

[1/s4] The treatment end date is the latest end date of an exposure record with a dose.

Meaning: An exposure record has a dose when EXDOSE is above zero, or when EXDOSE is zero and EXTRT contains PLACEBO. Which partial dates take part is decision trt.date.imputation.

[1/s5] A partial exposure date is not completed and is left out of the treatment dates.

Meaning: The treatment start and end dates are taken from the exposure dates that have a year, a month and a day.

[1/s6] Study day 1 is the treatment start date.

Meaning: There is no study day 0. The day before study day 1 is day -1.

## 2 Analysis populations and disposition (mod-populations)

[2/s1] The randomized set holds every randomized subject.

Meaning: A subject is randomized when the planned arm code (DM.ARMCD) is present and is neither SCRNFAIL nor NOTASSGN.

[2/s2] The safety set holds every subject who received at least one dose of study treatment.

Meaning: A subject received a dose when the treatment start date is present. A subject is randomized when the planned arm code (DM.ARMCD) is present and is neither SCRNFAIL nor NOTASSGN; the rule of the randomized set (pop.randomized.rule) does not enter.

[2/s3] Safety analyses group subjects by actual treatment.

Meaning: The decision holds for every output whose analysis set is the safety set. Outputs on another analysis set group subjects by planned treatment.

[2/s4] The end-of-study record is the disposition event record of the subject.

Meaning: The DS record with DSCAT equal to DISPOSITION EVENT. Of several such records the last by DSSEQ is taken. The record gives the end-of-study date (its DSSTDTC) and status: COMPLETED when DSDECOD is COMPLETED, DISCONTINUED for any other term, ONGOING when the subject has no such record.

## 3 Demographics and baseline characteristics (mod-demographics)

[3/s1] Age groups are below 65, 65 to 80, and above 80 years.

Meaning: The groups are labelled <65, 65-80 and >80. An age of exactly 80 is in 65-80.

[3/s2] Race categories are shown as collected and are not pooled.

[3/s3] Baseline weight and height are the last non-missing values on or before the treatment start date.

Meaning: The last value is the latest by the collected date and time; of the values of one day, a value without a collected time comes before those with a time, and the highest VSSEQ breaks a remaining tie. A subject without a treatment start date has no baseline weight and height.

[3/s4] Baseline body mass index is derived from baseline weight and height and rounded to one decimal.

Meaning: Weight in kg divided by the square of height in m; rounding is half away from zero.

## 4 Adverse event emergence (mod-ae-emergence)

[4/s1] A partial adverse event start date with a known month is completed with the first day of that month, or with the treatment start date when it falls in that month.

Meaning: A date with an unknown month is not completed.

[4/s2] An adverse event is treatment-emergent when it starts on or after the treatment start date.

Meaning: Dates are compared; times are ignored. For every alternative: an event of a subject without a treatment start date is not treatment-emergent; an event that ends before the treatment start date is not treatment-emergent; an event without an analysis start date is treatment-emergent.

[4/s3] Treatment emergence has no end date.

## 5 Baseline and analysis visits (mod-bds-visits)

[5/s1] Baseline is the last non-missing value before the first dose.

Meaning: A value is before the first dose when its date is before the treatment start date. A value on that date is before the first dose unless both its time and the time of the first dose were collected and its time is not earlier. The last value is the latest by the collected date and time; of the values of one day, a value without a collected time comes before those with a time, and the highest sequence number breaks a remaining tie. Whether records of unscheduled visits may be baseline is decision bds.unscheduled.use.

[5/s2] Post-baseline records keep their collected visit as the analysis visit.

Meaning: The target day of the visit is its planned study day (VISITDY). A record of an unscheduled visit has no analysis visit. A record is post-baseline when its date is after the treatment start date.

[5/s3] Of several records in one analysis visit, the one closest to the target day is analyzed, and the earlier one on a tie.

Meaning: Only non-missing values compete. Earlier and later are by the collected date and time; of the values of one day, a value without a collected time comes before those with a time, and the sequence number breaks a remaining tie.

[5/s4] Records of unscheduled visits compete for baseline and for analysis visits.

Meaning: A visit is unscheduled when it has no planned study day (VISITDY is missing).

[5/s5] An end-of-treatment record repeats the last non-missing post-baseline value on or before the treatment end date.

Meaning: The record has the analysis visit End of Treatment and the derivation type LOV. A subject without a treatment end date takes the last post-baseline value.

## 6 Table of demographic and baseline characteristics (tfl-demographics)

[6/s1] The planned outputs include the demographics table.

[6/s2] The analysis set of the demographics table is the randomized set.

[6/s3] The treatment columns of the demographics table are in ascending order of dose, with placebo first.

Meaning: Each column is headed by the treatment and the number of subjects of the analysis set in it.

[6/s4] A total column of the demographics table pools all treatment arms.

Meaning: A total column is the last column.

[6/s5] Percentages in the demographics table are based on the number of subjects of the analysis set in the column.

[6/s6] Percentages in the demographics table have one decimal, and a count of zero is shown without a percentage.

[6/s7] Quantiles in the demographics table follow SAS definition 5, the empirical distribution function with averaging.

[6/s8] Displayed numbers in the demographics table are rounded half away from zero.

Meaning: A number is rounded once, from its full precision to the displayed decimals.

[6/s9] In the demographics table, the mean and the median have one more decimal than the data, the standard deviation has two more, and the minimum and the maximum have as many as the data.

Meaning: The decimals of the data are the largest number of decimals among the values summarized in the row. Quartiles are shown as the median is.

[6/s10] P-values in the demographics table have three decimals, and a value below 0.001 is shown as <0.001.

[6/s11] Continuous rows of the demographics table show n, mean, standard deviation, median, minimum and maximum.

[6/s12] The demographics table shows no comparison between treatments.

Meaning: A comparison adds one p-value column after the treatment columns. The analysis of variance is one-way, with treatment as the factor.

## Decisions without a default

This standard sets no default for the decisions below. The study documents state them, or a person is asked. They are never guessed.

- `pop.efficacy.rule`: Who is efficacy-evaluable?
- `ae.related.values`: Which causality values count as related to study treatment?
- `tfl.demog.rows`: Which characteristics does the demographics table show, in which order?
- `tfl.vs.scope`: Which parameters and analysis visits does the vital signs table show?
